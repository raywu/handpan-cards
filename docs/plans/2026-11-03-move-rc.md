# Move RC: arm the handpan.raywu.org -> handpantheory.com saved-scale handoff

Mode: plan only (not executed). Drafted 2026-11-02 against main `85942c0d`, dev `3ebfa942`. Workstream key: TRI-29 (domain move).

## 1. Goal
One release that sets `MOVE_FROM = "handpan.raywu.org"` and `MOVE_TARGET = "https://handpantheory.com"` in `index.html`, so a visit to the old host forwards every saved scale (and hidden seeds) that fits under `MOVE_CAP` to the new host. It reaches main only after a served-DEV e2e on two Cloudflare branch-preview hosts proves every saved scale transfers, and after the owner's iPhone Safari pass and merge.

## 2. Non-goals
- No change to move logic (`moveForward`, `moveImport`, `moveCanon`, `MOVE_CAP` stay byte-identical to main). Any logic fix found by the e2e is a separate, re-planned lane.
- No CF dashboard, DNS, registrar or Redirect Rule action by the agent. Forwarding (CF-level) stays OFF.
- No GA property change (referral exclusion is an owner action, listed in section 12 only if O2 = b).
- No Safari 7-day storage work (queued-safari-7day-storage, after this workstream).
- No qa-seed on the DEV root or prod; no seeder outside the preview aliases or 127.0.0.1.
- Unless O2 = b: no canonical, og:url, JSON-LD, sitemap, robots, llms or scale-page host change.
